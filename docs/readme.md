# Thinks about XLSX Chart configuration

## Chart Configuration elements

- **Chart Title**: The title of the chart

- **Chart Type**: The type of the chart (e.g. line, bar, pie, etc.)

- **Chart Data**: The data that the chart will display

- **Data Labels**: The labels for the data

- **Data Series Colors**: The colors of the chart

- **Data Dots Colors**: The color of the dots in the chart

- **Chart Legend**: The legend of the chart

- **Chart Axis'**: The axis of the chart

- **Chart Gridlines**: The gridlines of the chart
